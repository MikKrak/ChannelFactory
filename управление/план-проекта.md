# Организационный план ChannelFactory

**Текущее состояние:** создан ChatGPT-проект ChannelFactory, управляющий чат перенесён в проект; согласованы начальные роли и имя будущего каталога программы `CF-application/`.

## DONE — принятые решения

- Единый репозиторий `MikKrak/ChannelFactory` для документов, управления и будущих исходников.
- Модель вертикальных связей HTP, адаптированная без избыточной иерархии.
- Три начальные роли: 00C (управление), 01C (концепция), 02C (разработка).
- Для GitHub используем подключённый плагин напрямую, без обязательного Work.
- Целевая схема: Mac для локальной разработки/длительных задач, GitHub для исходников, Vercel Hobby для тестового FastAPI/webhook, Supabase для данных. Подробности в `WORK_PLAN.md`.
