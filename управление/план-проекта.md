# Общий план ChannelFactory

**Цель:** завершить подготовку локальной программы и затем проверить серверную версию на Vercel.

**Сделано:** исходники в GitHub (`CF-application/`), резервная копия сохранена, приложение запущено на Mac; владелец проверил меню, материалы, черновики и Supabase.

## Следующие шаги
1. Проверить приложение на Mac после косметической ревизии CF-02C-004. `requirements.txt` уже добавлен (CF-02C-003); по решению владельца от 14.10.2026 чистую установку проверить при подготовке Vercel, сохранив рабочую `.venv`.
2. Завершить проверку обмена GitHub ↔ Mac.
3. Продолжать разработку в `main` и проверять изменения на Mac.
4. Перед серверным этапом решить вопрос доступа к редактору, создать `production` из одобренного коммита и настроить Vercel на эту ветку. Проверить Preview.
5. Испытать Vercel и операции с тестовыми данными Supabase. Telegram webhook — отдельный следующий этап.

**Правило выпуска:** `main` не обновляет рабочую версию Vercel. Перенос в `production` — только после проверки и решения владельца. Защиту редактора сейчас не делаем; до публичного доступа она обязательна.
