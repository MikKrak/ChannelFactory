# Общий план ChannelFactory

Обновлено: 16.10.2026.

**Текущий этап:** локальная разработка и отладка на Mac. Программные файлы по умолчанию меняются локально; владелец синхронизирует согласованные промежуточные результаты через GitHub Desktop. Документы проекта ведём через GitHub-плагин.

## Приоритеты

1. Согласовать первый пользовательский сценарий, сущности и связи, затем определить следующий объём работ по концепции и интерфейсу. Демонстрационный прототип 02C пока не означает утверждения структуры продукта.
2. Продолжать локальную доработку приложения. Цикл синхронизации с комментариями подтверждён 02C; испытания после последних изменений и отложенная ошибка Internal Server Error учитываются отдельно.
3. По [делу CF-00C-001 — Система управления проектом с навигацией](00C/дела/CF-00C-001-навигация-проекта.md) согласовать небольшой набор реальных Markdown-документов и объём следующей проверки на основе опыта 03C.

## Иерархия планов

Этот документ задаёт общие приоритеты. [План 00C](00C/план.md) отражает цели, ближайшие шаги и состояние подчинённых направлений. Подробные планы и ссылки на задания остаются у исполнителей: [01C — Концепция](01C/план.md) · [02C — Разработка](02C/план.md) · [03C — Исследования](03C/план.md).

Планы направлений приняты 00C 16.10.2026. Предложения в них требуют согласования; приёмка плана не запускает реализацию.

## Отложенный серверный этап

Vercel сейчас не запускаем. Чистую установку по существующему requirements.txt проверим при его подготовке, сохранив рабочую .venv. Перед выпуском отдельно согласовать проверенный коммит, защиту редактора, тестовые данные, production и политику Preview. main — рабочая бета; production — одобренная публичная версия для будущего Vercel. Перенос — только по решению владельца.

Подтверждённые технические результаты — в [STATUS](../STATUS.md); при расхождении учитывать более свежие отчёты и решения владельца.
