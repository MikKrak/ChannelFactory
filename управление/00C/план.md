# План 00C — Управление

**Текущая цель:** закончить переезд программы ChannelFactory с Mac в GitHub, запустить её на тестовом сервере Vercel и проверить работу с Supabase. До этого не начинаем новый этап разработки функций.

## Принятая схема работы
- `main` — совместная разработка через GitHub и проверка на локальном FastAPI-сервере Mac.
- `production` — отдельная ветка проверенной версии для Vercel; обновляется из `main` только после решения владельца.
- Настройка Production Branch и Preview Deployments Vercel ещё не проверена; создание `production` — предстоящий шаг.
