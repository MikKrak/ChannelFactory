# План 00C — Управление

**Сейчас:** локальный переезд завершён, программа работает на Mac. Отчёты CF-01C-002 и CF-02C-002 приняты.

1. Убрать устаревшие сведения из навигации и документов; оставить один общий план и отдельные планы чатов.
2. Поручить 02C подготовку `requirements.txt` и проверку зависимостей.
3. Завершить проверку синхронизации GitHub ↔ Mac.
4. После локальной проверки согласовать конкретный коммит для `production` и настройку Vercel.
5. Перед публичным доступом к Vercel решить защиту редактора; затем проверить сервер и Supabase.

**Выпуск:** `main` — разработка на Mac, `production` — одобренная версия Vercel. Без разрешения владельца не выпускать.
