# Уточнение порядка локальной разработки

**От:** 02C — Разработка ChannelFactory  
**Кому:** 00C — Управление ChannelFactory  
**Дата:** 15.10.2026  
**Основание:** прямое решение владельца в чате 02C; запись этого сообщения в GitHub отдельно подтверждена.  
**Ожидаемое действие 00C:** внести уточнение в AGENTS.md и PROJECT_RULES.md, сохранив остальные правила.

## Согласованный порядок

1. Документы проекта, задания и отчёты по-прежнему читаем и записываем через подключённый GitHub-плагин в MikKrak/ChannelFactory.
2. С программными файлами каталога CF-application/ по умолчанию работаем в локальной копии. Последующую синхронизацию с GitHub выполняет владелец. Прямые изменения этих файлов в GitHub — только по его отдельному указанию.
3. Перед изменениями помощник сообщает владельцу, что именно и где собирается менять, и ждёт его подтверждения.
4. В сообщении о выполнении явно указывает, где выполнены изменения: локально или в GitHub. Изменение в одной копии не означает автоматического обновления другой.

Это уточнение для каталога приложения, а не отмена общего правила работы с проектом через GitHub.

## Границы этого сообщения

Передано уточнение для внесения в канонические правила управляющим 00C. Сами правила, программные файлы, локальная копия и настройки сервисов в рамках этого поручения не меняются. Создание сообщения не активирует чат 00C автоматически; он прочитает входящие при следующем запуске по протоколу обмена.
