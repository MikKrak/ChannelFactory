## Что готово

В общей шапке постоянно доступны две компактные кнопки: «Второе окно» и меню расположения. Первая открывает только `about:blank`; пользователь сам вводит любой адрес в штатной строке браузера. Автоматических переходов на ChatGPT или другой сайт больше нет. Вторая показывает шесть наглядных схем: Рядом, Сверху/снизу, Наложение, Фабрика крупно, Второе крупно, macOS Split View.

Сохранены прежние обработчики, разметка шапки, стили, защита от дублей и отдельная чистая модель окна. Новые схемы не вызывают навигацию существующего окна. Выбранная схема и отметка первого открытия сохраняются локально в браузере. Используется новый ключ `cf.browser-window.v1`: прежняя отметка ChatGPT не превращается в отметку нейтрального окна.

Содержимое, URL, сообщения, cookie и формы второго окна не читаются. Нет собственной адресной строки, iframe, передачи текста/вложений, API или работы с аккаунтами. Начальный opener отсоединяется. После обновления фабрики или потери WindowProxy автоматический дубликат не открывается: есть ручной возврат и отдельная явная команда «Я закрыл окно — открыть снова». `closed=true` не считается доказательством закрытия: так же проявляется COOP.

## Автоматически / вручную / недоступно

| Действие | Результат |
|---|---|
| Открыть нейтральную страницу по нажатию | Работает. Тип окна/вкладки окончательно выбирает Safari |
| Вернуть доступное окно | Запрос focus без перезагрузки; при запрете — понятный ручной возврат |
| Переместить/изменить размер второго окна | Запрос стандартных moveTo/resizeTo, затем проверка только геометрии; без подтверждения показывается ручной путь |
| Переставить основное окно фабрики | Вручную; обычное многовкладочное окно Safari ранее не подчинилось API |
| Скрыть второе окно | Вручную «Окно → Убрать в Dock»; кнопка фабрики лишь запрашивает фокус, не закрывает чужую страницу |
| Системный macOS Split View | Ручная инструкция в отдельной схеме; автоматический запуск не обещается |
| Надёжно управлять чужой страницей после навигации/COOP | Недоступно и не реализовано |

Safari проверен практически: принудительный popup открывает отдельное окно и допускает геометрию, но оставляет ограниченную панель без полноценного редактируемого адресного поля. Для универсального назначения выбран обычный браузерный интерфейс (`popup=no`, запрос штатных панелей). В текущих настройках Safari он открывается вкладкой. Проверена штатная команда **«Окно → Переместить вкладку в новое окно»**: получается самостоятельное обычное окно с редактируемой адресной строкой. Этот короткий шаг постоянно показан в меню фабрики. Настройки Safari не менялись.

После такого переноса запрос геометрии обычного окна не подтвердился: интерфейс корректно предложил ручное размещение. Успешные результаты прежней нейтральной пробы не выдаются за автоматическую раскладку итогового обычного окна: popup 650×550 на (50,80) переместился и изменился до 700×650 на (180,120); основное окно осталось 1440×870 на (0,30). Измерения только геометрии, без чтения содержимого.

Split View: проверено наличие штатного меню Safari **«Окно → Плитка на весь экран → Слева на экране / Справа на экране»**. Инструкция: поместить фабрику слева, выбрать второе окно справа, менять доли центральным разделителем; это одно полноэкранное пространство macOS, не обычное размещение рядом. **Фактическое образование пары Split View и перемещение её разделителя в этом опыте не подтверждены**; автоматического веб-вызова нет. Попытки системных команд не трактуются как успешная проверка. Исследование остановлено в установленном малом бюджете.

## Один возможный следующий шаг

Если обязательна автоматическая раскладка **двух обычных окон**, наиболее прямой вариант — **необязательный локальный компонент macOS только для геометрии окон**. Он получает явное разрешение «Универсальный доступ», меняет положение/размер/фокус, не читает содержимое страниц. Ориентировочная сложность средняя: несколько рабочих дней на небольшой прототип и проверку; оценка предварительная, денежная стоимость зависит от исполнителя, сервисные AI-платежи не нужны. Доставку/обновление и границы разрешений надо согласовать отдельным заданием. Ничего такого в 015 не создавалось.

Для приёмки: обновить существующую вкладку 8012, открыть меню расположения; «Второе окно» → при необходимости вынести созданную вкладку в окно штатной командой Safari → вручную ввести любой сайт. Фабрика не управляет этим содержимым. Коммит исходников и синхронизацию делает владелец через Desktop.
