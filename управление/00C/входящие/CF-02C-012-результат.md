## Готово локально

- «Проект → Источники проекта» разделяет подключённые источники и доступные для подключения. В строке подключённого RSS есть «Настроить», тип, использующие проекты, сведения о последней загрузке.
- Настройка открывается по /studio/{project}/sources/{source_id}/filter в проектном пространстве. Оболочка, вкладка источников и навигационная цепочка сохраняют проект. Старый GET общей страницы с project перенаправляется в проектный адрес. Формы POST используют проектный адрес; подмена поля project не может сменить проект из URL. Старый POST оставлен для совместимости с уже открытыми страницами.
- Общий каталог фабрики показывает использующие проекты, но не содержит назначения/подключения. Общая карточка редактирует название/URL/описание; проектная карточка не дублирует эти формы и явно ведёт в общую карточку. Создание общего источника из проекта — явный переход к фабрике. Прежние серверные POST оставлены для совместимости, но в настройке нет форм импорта, отбора, публикации или ответов.
- Три области: исследование, правила, результаты. На широком экране стоят рядом и независимо прокручиваются; на узком — друг под другом с ограниченными списками. Скрываемый инспектор показывает источник, проект, адрес и сохранённую версию.
