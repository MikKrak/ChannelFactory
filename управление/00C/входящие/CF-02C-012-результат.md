### Что сделано

- Правила версии 2: у каждой рубрики два видимых состояния, команды «Включить все/Исключить все», идемпотентное переключение одной строки, немедленная синхронизация списка и полей. Состояние новых рубрик задаётся явно. Одна включённая рубрика даёт основание даже при других исключённых.
- Включающие фразы сочетаются с рубриками через И/ИЛИ. Исключающие фразы — отдельный запрет. Без рубрик можно подтвердить тему включающей фразой; при недостатке данных — понятная неопределённость. Каждое решение объясняется. Это не редакционная оценка качества.
- Независимый «Фильтр включён/выключен», исходно выключен. Выключение сохраняет правила и не запускает рабочих операций. При импорте с сохранённой новой конфигурацией выключенный фильтр не ограничивает тему; допуск самого подключения источника остаётся отдельным рабочим условием. Старые подключения без сохранённой конфигурации не переводятся в новый режим автоматически.
- Автосохранение завершённого изменения поля (потеря фокуса), списка или рубрики, без обязательной кнопки/повторной галочки и без отправки каждого символа. Статусы «Сохраняется…», «Сохранено», «Ошибка сохранения». Простое открытие, чтение выборки и уход без правок не сохраняют даже начальные настройки.
- В базе хранится целый валидный действующий снимок. Незавершённый/ошибочный текст хранится только локальным черновиком, не заменяет его. Поэтому отдельные колонки редактируемого и действующего JSON не понадобились. Выключить фильтр можно и при ошибочном тексте: отдельно записать выключатель поверх последней подтверждённой конфигурации, не потеряв ввод. Включение при ошибке запрещено.
- Запросы одного окна сериализованы, последние ожидающие изменения объединяются. Контроль ревизии и блокировка БД сохранены. Неизвестный исход запроса сверяется чтением, без слепой повторной записи. Конфликт не подменяет ожидаемую ревизию чужой; нужно явно открыть сохранённую версию. Предыдущий локальный вариант остаётся резервной копией браузера.
- Внутренние ссылки и выбор проекта завершают сохранение. Если это невозможно — диалог приложения: остаться или перейти с локальным черновиком. Невалидный ввод восстанавливается тоже. Восстановленный незавершённый черновик не применяется просто от нового ухода со страницы. При недоступном localStorage уход с ошибкой блокируется. Закрытие/внешний уход/Browser Back не обещаются без системного диалога.
- Первоначальная подсказка только по совпадению слов имени/описания проекта и рубрик, без LLM/моделей/новых зависимостей. Нет оснований — нет предложения. Предложение явно говорит, какие рубрики включить и что остальные будут исключены. До «Использовать предложение» нет ни сохранения, ни включения; принятие не меняет выключатель.
- Версия 1 сохраняет прежнюю семантику. Новая страница не преобразует её при открытии: требуется явное «Создать новый вариант». Прежние данные не переосмысливаются молча.
- Рабочее место использует прежние три области/инспектор/компактную строку. Итоги вне прокрутки, подсказки по касанию/клавиатуре, русские имена полей с исходными именами как справкой. Убрана лишняя прокрутка всей страницы на ноутбуке. Версионированы адреса новых JS/CSS, чтобы локальная синхронизация не оставляла старые файлы в кэше браузера.
