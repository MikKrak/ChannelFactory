# Структура чатов ChannelFactory

**Статус:** согласованная начальная организационная модель. Новые специализированные чаты ещё предстоит создать вручную в проекте ChatGPT ChannelFactory.

```text
00C — Управление ChannelFactory (текущий чат)
├── 01C — Концепция ChannelFactory (планируется)
└── 02C — Разработка ChannelFactory (планируется)
```

## 00C — Управление

Общий план, приоритеты, утверждение решений владельцем, постановка заданий, приём результатов и согласование границ между направлениями. Не подменяет специализированную разработку и не считает предложения утверждёнными автоматически.

## 01C — Концепция

Продуктовая модель, функции, сценарии использования, исследования и открытые вопросы. Исходная каноническая концепция — `CONCEPT.md`. Не изменяет согласованные принципы без решения владельца через 00C.

## 02C — Разработка

Программная архитектура, исходники, тестирование, интеграции Supabase, Telegram и Vercel. Исходный код планируется в `CF-application/`, но сейчас работающая локальная копия находится на Mac и ещё не перенесена. Первый этап — инвентаризация и безопасный план переноса, без самовольной модификации локального прототипа.

## Принцип

Роли сохраняются в GitHub независимо от конкретных физических чатов. Новые роли вводятся только при реальной необходимости. Передача заданий и результатов — по `управление/иерархический-обмен.md`.
