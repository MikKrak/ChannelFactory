# Структура чатов ChannelFactory

**Статус:** действующие роли проекта; 03C — Исследования добавлен владельцем 15.10.2026.

```text
00C — Управление ChannelFactory
├── 01C — Концепция ChannelFactory
├── 02C — Разработка ChannelFactory
└── 03C — Исследования
```

## 00C — Управление

Общий план, приоритеты, утверждение решений владельцем, постановка заданий, приём результатов и согласование границ между направлениями. Не подменяет специализированную разработку и не считает предложения утверждёнными автоматически.

## 01C — Концепция

Продуктовая модель, функции, сценарии использования, исследования и открытые вопросы. Исходная каноническая концепция — `концепция/CONCEPT.md`. Не изменяет согласованные принципы без решения владельца через 00C.

## 02C — Разработка

Программная архитектура, исходники, тестирование, интеграции Supabase, Telegram и Vercel. Исходники находятся в `CF-application/`. Программные файлы по умолчанию меняются локально; в GitHub — по прямому указанию владельца. Синхронизацию выполняет владелец через GitHub Desktop.

## 03C — Исследования

Проверка источников, изучение возможностей и ограничений, сравнение вариантов по вопросам владельца и 00C. Отделяет факты от гипотез и рекомендаций; предложения не становятся решениями автоматически. Не подменяет утверждение концепции 01C или реализацию 02C.

Рабочая папка — `управление/03C/`; [краткий план](03C/план.md). Задания — `управление/03C/задания/` после первого поручения, результаты — в `управление/00C/входящие/` по общему протоколу.

## Принцип

Роли сохраняются в GitHub независимо от конкретных физических чатов. Новые роли вводятся только при реальной необходимости. Передача заданий и результатов — по `управление/иерархический-обмен.md`.
