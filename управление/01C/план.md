# План 01C — Концепция

**Текущая цель:** помочь проверить переезд работающей программы. Новые функции и большой пересмотр концепции пока отложены.

## Что делаем
1. Прочитать `STATUS.md`, `концепция/CONCEPT.md` и `разработка/WORK_PLAN.md`.
2. Составить **короткий, но конкретный список пользовательских проверок** уже работающего прототипа: открыть редактор, увидеть материалы, подготовить пост, проверить сохранение, проверить отображение статуса публикации. Отметить, что из этого подтверждено документами, а что нужно проверить на новой копии.
3. Отдельно указать действия, которые нельзя выполнять автоматически при проверке: публикация в действующий канал, ответы читателям, изменение рабочих данных без разрешения.
4. Передать список 00C в `управление/00C/входящие/`. Не менять программу и не объявлять неподтверждённые функции работающими.
5. После запуска на Vercel сравнить реальные результаты с этим списком; передать 00C найденные проблемы.

## Что считать результатом
Есть понятный список «действие пользователя → что должно произойти → как проверить», пригодный для проверки локальной и серверной версии. В нём нет требований создавать новые функции.

**Следующий шаг:** выполнить пункты 1–4. Новые продуктовые решения из первого отчёта пока не рассматриваем.
