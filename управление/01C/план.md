# План 01C — Концепция

Обновлено: 16.10.2026.

**Сводка для 00C:** цель — уточнять продуктовые сценарии ChannelFactory и сохранять согласованность с [концепцией](../../концепция/CONCEPT.md). Ближайший шаг — приёмка этого плана и выбор 00C вопроса о первом полезном выпуске. Состояние после передачи отчёта — **требуется решение**. Препятствие для дальнейшей проработки: новое содержательное задание по концепции пока не согласовано.

## Подтверждённое состояние

[CF-01C-001](задания/CF-01C-001.md) и [CF-01C-002](задания/CF-01C-002.md) завершены; отчёт CF-01C-002 принят 00C. Концепция и цикл `main → Mac → одобрение → production → Vercel` согласованы. Предложения из отчётов не становятся решениями автоматически. Работа прежнего 01C продолжена по [передаче](передача-01C-2026-10-14.md).

## Текущая работа и следующий шаг

1. Завершить [CF-01C-003](задания/CF-01C-003.md): один актуальный план и [короткий отчёт для 00C](../00C/входящие/CF-01C-003-результат.md). Результат — 00C видит цель, ближайший шаг, состояние и зависимости направления.
2. После передачи отчёта получить решение 00C: **согласовать ли границу первого полезного выпуска, предложенную в [CF-01C-001, §3](../00C/входящие/CF-01C-001-результат.md#3-пять-вопросов-для-решения-00c), или пока оставить 01C в ожидании?** Новую проработку начинать по принятому решению и заданию.

## Предложения на согласование

Ближайший продуктовый вопрос — что владелец должен суметь сделать в первом полезном выпуске и по каким результатам его принять. После выбора границы уточнить разрешённую автономность и первый сценарий ответа читателю. Смысл публикации в нескольких каналах, условия использования материалов и хранения обращений — следующие вопросы, их приоритет выбирают владелец и 00C. Исходные предложения — в [CF-01C-001, §3](../00C/входящие/CF-01C-001-результат.md#3-пять-вопросов-для-решения-00c); включение сюда не разрешает их выполнение или изменение концепции.

## Отложено и зависимости

- Vercel сейчас не запускаем; чистая установка отложена до его подготовки. Разработка идёт локально на Mac, синхронизацию с GitHub выполняет владелец через GitHub Desktop в согласованных точках.
- Перед будущими серверными испытаниями по отдельному поручению уточнить доступ к редактору, тестовые записи и разрешённые действия; основа — [CF-01C-002, §2–3](../00C/входящие/CF-01C-002-результат.md#2-что-нужно-уточнить-в-документах-и-порядке-выпуска). Ожидаемый результат — согласованные пользовательские проверки. После испытаний сообщить 00C о расхождениях.
- Подтверждённые локальные проверки без причины не повторять. Новые функции, переписывание концепции и задачи соседним чатам не начинать. Решения владельца/00C и результаты технических испытаний определяют дальнейший порядок.
