# CF-02C-001 — Подготовка безопасного переноса приложения

**От:** 00C — Управление ChannelFactory  
**Кому:** 02C — Разработка ChannelFactory  
**Статус:** OPEN  
**Приоритет:** первый запуск роли

## Цель
Подготовить проверяемый план безопасного переноса работающего локального FastAPI-прототипа с Mac в `CF-application/` существующего GitHub-репозитория и последующего тестового развёртывания на Vercel.

## Обязательный контекст
Прочитать `INDEX.md`, `PROJECT_RULES.md`, `AGENTS.md`, `STATUS.md`, `разработка/WORK_PLAN.md`, `разработка/DEVELOPMENT.md`, `управление/структура-чатов.md` и `управление/иерархический-обмен.md`.

## Работа
1. Составить список сведений, которые нужно проверить в локальной папке Mac: файлы, зависимости, `.git`, `.gitignore`, конфигурация и секреты (значения секретов не запрашивать и не публиковать).
2. Предложить безопасный порядок резервного копирования, объединения с существующим репозиторием, проверки локального запуска и GitHub Desktop.
3. Обозначить будущую структуру `CF-application/` и требования к Vercel Root Directory без предположения о фактическом расположении Python-модулей.
4. Перечислить риски: потеря локальных изменений, случайный коммит `.env`, сломанные импорты, несовместимые фоновые задачи, доступ к редактору.
5. **Не переносить, не переписывать и не публиковать исходники** до отдельного согласования с владельцем.

## Результат
Записать сообщение в `управление/00C/входящие/CF-02C-001-результат.md` с пошаговым планом и конкретными проверками, которые потребуется выполнить владельцу на Mac.

## Критерий приёмки
Есть безопасный план миграции без изменений локального прототипа, без секретов в GitHub и без преждевременного развёртывания.
