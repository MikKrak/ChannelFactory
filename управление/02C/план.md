# План 02C — Разработка

**Текущая цель:** безопасно перенести существующий локальный FastAPI-прототип в GitHub, затем запустить и проверить тестовую серверную версию.

## Что делаем по порядку
1. **Mac:** вместе с владельцем проверить папку программы, список файлов, наличие Git, команду запуска и зависимости. Не запрашивать значения секретов. Убедиться, что есть проверенная резервная копия.
2. **GitHub:** клонировать существующий `MikKrak/ChannelFactory` в отдельную папку; подготовить исключения для секретов; скопировать только проверенные исходники в `CF-application/`. Не перезаписывать исходную папку и не создавать новый репозиторий вместо существующего.
3. **Локальная проверка:** запустить программу из нового клона и проверить основные страницы и действия на согласованных тестовых данных. При ошибке не исправлять оригинал вслепую.
4. **Обмен изменениями:** проверить GitHub → Mac и Mac → GitHub через GitHub Desktop. Зафиксировать конкретные коммиты и результаты.
5. **Vercel:** после отдельного согласования настроить тестовый проект с Root Directory `CF-application`, проверить зависимости, переменные окружения и защиту редакторских маршрутов.
6. **Supabase:** проверить чтение и запись тестовых данных через сервер. Не менять рабочие данные без разрешения.
7. **Telegram:** отдельно, после успешной серверной проверки, реализовать и испытать webhook; не публиковать в действующий канал автоматически.
8. **Отчёт:** записывать в `управление/00C/входящие/` проверенные результаты, ошибки, ссылки на коммиты и следующий шаг. Подтверждённые изменения состояния предлагать для `STATUS.md`.

## Когда работа завершена
Код в GitHub без секретов, новая локальная копия работает, обмен GitHub Desktop проверен, сервер открывается с защищённым редактором и читает/записывает тестовые данные в Supabase. Telegram — отдельная завершающая проверка после запуска сервера.

**Следующий шаг:** дождаться от владельца фактического состава папки Mac и подтверждения резервной копии. Подробная безопасная процедура уже записана в `управление/00C/входящие/CF-02C-001-результат.md`. Не начинать перенос до этой проверки.
