## Границы текущей работы

Общая библиотека использует существующие источники/материалы, проектные ссылки не копируют содержимое. Только один реальный проект СССР; минимальные связи для будущих проектов допускаются заданием 009. Навигатор, универсальный Engine, планировщик, AI, новые адаптеры, webhook/туннели, Vercel и публичный редактор не входят в задачу. Права отправки не менять. Рабочая миграция отдельно согласуется, удаление материалов в этой версии отсутствует.

Неизвестный результат сохранения/отправки не разрешает слепой повтор. Захват получателя БД автоматически не истекает; перед восстановлением остановить прежний процесс.

## Данные и последующие решения

Временный SQLite /private/tmp/cf-incoming-007-20261030/events.sqlite3 не используется регулярным получателем; срок до 31.10.2026 04:12 Рига. Удаление отдельно решает владелец; копия пока не удалена.

Автоочистка рабочей базы выключена. Окончательный срок хранения payload/переписки определяет владелец. Предложение прежнего этапа — пересмотр исходных payload не позднее 7 дней после опыта; это не утверждённый автоматический срок. Дедупликационные ключи, курсор и receipts нельзя просто удалять по offset.

Код меняем локально, синхронизация владельцем; документы через GitHub-плагин. Секреты/.env не менять.
